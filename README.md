<h1 align="center">Il Gelato</h1>

<p align="center">Italienisch lernen mit il gelato – für jedes richtige Wort gibt es eine Kugel.</p>

---

Eine kleine Vokabel-App als einzelne HTML-Datei. Läuft im Browser, ohne
Installation und ohne Konto. Auf dem iPad lässt sie sich über Safari →
Teilen → „Zum Home-Bildschirm" als Vollbild-App ablegen.

**Üben kann man:**

- mit Karten zum Umdrehen
- durch Auswählen aus vier Antworten
- durch Selberschreiben

in beide Richtungen, mit italienischer Aussprache und einer Kugel Gelato
für jedes richtige Wort.

**Dateien**

| Datei | Zweck |
|---|---|
| `index.html` | die komplette App, Icon und Programm eingebettet |
| `IlGelato-Icon.png` | das Icon separat |
| `robots.txt` | hält Suchmaschinen und KI-Crawler fern |

---

Private Lernhilfe zum Üben zuhause. Das Wortmaterial stammt aus dem
Italienisch-Lehrmittel der Schule und wird ausschliesslich zum
persönlichen Lernen verwendet. Keine Verlagspublikation, kein
kommerzielles Angebot.
