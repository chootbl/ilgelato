IL GELATO – Italienisch lernen
als App auf den iPad-Home-Bildschirm
=====================================

In diesem Ordner liegen:
  index.html   die fertige App (Icon und Programm sind eingebettet)
  robots.txt   haelt Suchmaschinen fern


VARIANTE A – GitHub Pages (dauerhaft, gratis)
---------------------------------------------
1. Konto auf github.com anlegen (falls noch keines vorhanden).
2. Oben rechts auf "+" -> "New repository".
   Name unauffaellig waehlen, Sichtbarkeit "Public", anlegen.
   WICHTIG: keine Lizenz-Datei hinzufuegen (siehe unten).
3. Im leeren Repository auf "uploading an existing file" klicken und
   index.html sowie robots.txt hineinziehen. Dann "Commit changes".
4. Reiter "Settings" -> links "Pages".
   Unter "Branch" den Eintrag "main" waehlen, Ordner "/ (root)", speichern.
5. Ein bis zwei Minuten warten, danach steht dort die Adresse:
   https://DEINNAME.github.io/REPONAME/


VARIANTE B – Netlify Drop (schneller, ohne Repository)
------------------------------------------------------
1. app.netlify.com/drop im Browser oeffnen.
2. Den Ordner "Website" auf die Flaeche ziehen.
3. Die Adresse erscheint sofort.


AUF DEM IPAD EINRICHTEN
-----------------------
1. Die Adresse in SAFARI oeffnen (nicht Chrome – nur Safari kann das).
2. Auf das Teilen-Symbol tippen (Quadrat mit Pfeil nach oben).
3. "Zum Home-Bildschirm" waehlen.
4. Namen bestaetigen ("Il Gelato") und auf "Hinzufuegen" tippen.

Die App startet danach im Vollbild, ohne Adress- und Tableiste.


ZUR LIZENZ-DATEI
----------------
Falls im Repository eine Datei LICENSE liegt (z. B. Apache 2.0):
loeschen. Eine Open-Source-Lizenz wuerde den gesamten Inhalt zur
freien Weiterverwendung freigeben – das laesst sich fuer Wortmaterial
aus einem Lehrmittel nicht wirksam erklaeren.
Auf GitHub: Datei oeffnen -> Papierkorb-Symbol -> Commit changes.


NEUE WOERTER NACHTRAGEN
-----------------------
Immer die Datei IlGelato.html im uebergeordneten Ordner bearbeiten,
danach nach Website/index.html kopieren und erneut hochladen.
Auf dem iPad genuegt anschliessend das Neuladen der App.
